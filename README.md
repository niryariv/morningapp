# Morning

Morning is a small, calm reading edition assembled once a day. It offers a finite mix of science, mathematics, history, nature, imagery, essays, and one Hebrew Wikipedia discovery—with no infinite scroll, urgency, engagement metrics, accounts, analytics, or paid services.

The interface is English. Articles may be English or Hebrew; Hebrew cards use right-to-left typography automatically. The reading size is adjustable and saved locally on the device. Light and dark colors follow the device preference.

## How it works

```text
Public RSS and APIs
        ↓
Scheduled GitHub Action
        ↓
Python collection and selection
        ↓
data/today.json + dated history
        ↓
Mirrored static data in docs/data
        ↓
HTML, CSS, and JavaScript on GitHub Pages
```

The browser never contacts source APIs. It only reads normalized JSON generated by the daily action. The canonical copy lives in `data/`; the generator mirrors publishable copies into `docs/data/` because GitHub Pages deploys `docs/` as a self-contained artifact.

## Sources

Source definitions live together in [`scripts/config.py`](scripts/config.py):

- NASA Astronomy Picture of the Day API
- Quanta Magazine RSS
- JSTOR Daily RSS
- NASA Earth Observatory RSS
- Smithsonian Magazine RSS
- Aeon RSS
- הידען (Hayadan) RSS
- Hebrew Wikipedia featured-article category through the MediaWiki API

Every source is public and free. The generator uses only feed/API metadata—titles, excerpts, links, and provided image URLs. It does not bypass paywalls, scrape full articles, or republish publisher content.

To add or remove an RSS source, edit `SOURCES` in `scripts/config.py`. Each entry supplies a publisher name, feed URL, default category, language (`en` or `he`), and source-quality weight. Set `long_read: true` for essay feeds; selection allows at most one such item per edition.

## Selection

Each feed candidate gets transparent heuristic scores for interest, timelessness, visual value, positivity, and publisher quality. English and Hebrew penalty terms lower the score for violence, political conflict, catastrophe, crime, and other high-arousal topics. No machine learning or external classifier is used.

The final pass:

1. Removes malformed entries and normalized URLs seen during the previous 30 days.
2. Keeps APOD and a date-seeded Hebrew Wikipedia featured-article discovery when available.
3. Reserves room for nature/geography and at most one long read.
4. Limits category and publisher repetition.
5. Chooses up to seven high-quality cards; it never adds weak material merely to hit a quota.

A failed source is logged and skipped. If every source fails, the last successful edition remains published. On a brand-new installation with no previous edition, `data/fallback.json` supplies a small bilingual shelf edition.

## Run locally

Python 3.11 or newer is recommended.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/update.py
python -m http.server 8000 --directory docs
```

Open <http://localhost:8000>. A local web server is needed only because browsers normally block JavaScript from reading JSON through `file://`; there is no application server or backend.

To generate a reproducible dated edition:

```bash
python scripts/update.py --date 2026-08-16
```

NASA's `DEMO_KEY` works without configuration. For a higher APOD rate limit, create a free NASA API key and set it locally:

```bash
export NASA_API_KEY="your-key"
python scripts/update.py
```

## Publish with GitHub Pages

1. Create a GitHub repository and push these files to its default branch.
2. If the repository is a fork, open **Actions** and enable its workflows.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **GitHub Actions** as the source.
5. Open **Actions → Update Morning edition → Run workflow** for the first manual update.

The same workflow checks out the repository's default branch, generates and validates the edition, commits the generated data, and deploys it. It uses the repository's built-in `GITHUB_TOKEN`; no personal access token is needed. The site uses relative URLs and therefore works at either a user domain or a project path such as `username.github.io/morning/`.

If the default branch is protected against Action commits, allow GitHub Actions to write to it or adjust the workflow to commit through your normal review process.

## Optional secret

`NASA_API_KEY` is the only supported secret and is optional. Add it under **Settings → Secrets and variables → Actions**. Without it, Morning uses NASA's public `DEMO_KEY`.

## Daily schedule

`.github/workflows/update.yml` runs at `03:15 UTC`. That is approximately 05:15 in Israel Standard Time and 06:15 during daylight-saving time. GitHub cron does not understand the `Asia/Jerusalem` daylight-saving transition, while the Python generator does use that timezone to name each edition correctly. Scheduled Actions can also start several minutes late.

## Archive and offline behavior

Each successful edition is saved as `data/history/YYYY-MM-DD.json` and mirrored to `docs/data/history/`. `docs/data/archive.json` powers the bounded previous/next navigation; it does not append an endless archive to the page. Deduplication examines the most recent 30 dates.

The small service worker caches the app shell and successfully opened edition files. This allows the most recently visited edition to remain readable offline after the first visit. Remote publisher images may not be available offline, and missing images are removed without breaking the card.

## Repository map

```text
.github/workflows/update.yml  Daily generation and Pages deployment
scripts/update.py             Orchestration, history, and selection
scripts/config.py             Feeds and scoring terms
scripts/feeds.py              RSS/Atom normalization
scripts/apod.py               NASA APOD API
scripts/wikipedia.py          Filtered Hebrew discovery
scripts/utils.py              Fetching, text, URLs, and JSON helpers
data/                         Canonical current, fallback, and history data
docs/                         Complete static site published to Pages
```

## Limitations

- Feed addresses and publisher metadata can change; source errors are isolated and visible in the Action log.
- Keyword scoring is intentionally simple. It reduces unwanted topics but cannot understand every context.
- Wikipedia discovery is selected deterministically from the first API page of Hebrew featured articles; this is a high-quality pool, but not the encyclopedia's entire featured collection.
- External images are referenced from their publishers and can disappear or reject hotlinking; the text card remains intact.
- There is no translation. English and Hebrew articles appear in their original language.
- The PWA uses a scalable SVG icon. Some older mobile launchers may prefer separately supplied PNG icons.
